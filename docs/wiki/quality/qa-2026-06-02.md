## Security notes

- Android enables FLAG_SECURE only while nsec is visible.
- iOS marks nsec text as privacy-sensitive and clears exported state on disappear/background, except while Passkey/Nosskey authentication is actively exporting.
- External signer sessions show account state but do not expose private-key export controls.
