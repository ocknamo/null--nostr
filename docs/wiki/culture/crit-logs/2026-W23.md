# Weekly Nuru Design Crit — 2026-W23 (2026-06-03)

## Summary

2026-06-03 の Design Crit。議題は [[../../strategy/themaday-2026-06-03-marketing-growth|ThemaDAY マーケティング・成長戦略 v2]] の 5 決議。

## Rationale

### A — Week-1 復帰率

第一条「日常を壊さない」に照らすと、単純な DAU / WAU / 滞在時間ではなく、**戻ってもらえる自然な理由があるか**を見るほうが適切。製品計測コードは ADR-0014 に従い入れず、manual cohort で観察する。

### B — 三声モデル

ぬるるを運営の宣伝役にすると ADR-0011 第二条・第三条に反する。運営の声、ぬるるの声、開発者向けの声を分離することで、表層のやわらかさと trust surface の厳密さを両立する。

### D — ICP 固定

90日で対象を広げると、コピー・導線・初回体験がぼやける。Phase 0 は日本語 Nostr 既存ユーザーとプライバシー意識ある一般ユーザーだけを主戦場にする。

### E — safe starter graph

空の Home は離脱要因。とはいえ、任意リレー生フィードの復活は安全上できない。safe starter graph は必要だが、リスト管理と悪用防止を先に設計する必要がある。

### C — bunker

ぬるる本体 npub の鍵管理は重要だが、拙速に運用すると信頼事故になる。NIP-46 bunker / 2-of-N は方向性として維持し、マーケティング Phase 0 の blocker から外す。
