# ADR-0008: 4軸自由ドクトリンを長期ミッションとして起票する

## Status

Proposed (長期ミッション。Charter v0.1 北極星の支柱として記録し、Phase ごとに ADR で具体実装を承認する)。

## Context

ぬるぬるは「Nostr で最も優れたデザインのクライアント」から「日本の日常を主権的に成立させるインターフェース」へ目的を一段引き上げる議論を行った。実装上の起点は以下の現実認識:

- **言論 / プライバシー** の中央集権検閲は既知。Nostr / Marmot がカバー領域。
- **経済活動** の検閲: Visa/Mastercard、決済代行、銀行口座開設拒否などにより、表現者・小規模事業者・特定業種のキャッシュフローが遮断されている。Bitcoin / Lightning がレールを提供する。
- **コード / コンテンツの配布** の検閲: App Store / Google Play / GitHub の審査・削除・凍結が増加。Nostr イベント (NIP-89 / kind 30023 / 署名付きバンドル) が代替レールを提供しうる。
- LINE が日本社会で持つ「チャット + ウォレット + ミニアプリ + ショッピング」の surface 統合は、中央集権レールの上の到達点。**ぬるぬるはこれを主権的レールで再演する**ことで業界10年先を取れる、というのが本 ADR の起点。

詳細な戦略は [[../culture/four-freedoms]] に記す。

## Decision

4つの自由 (言論 / プライバシー / 経済 / 配布) を、ぬるぬるの**長期ミッションとして正式に記録**する。

- **本 ADR は実装着手の承認ではない。** 軸 3 (経済) / 軸 4 (配布) の各 Phase 着手は、それぞれ別 ADR で承認する。
- **Charter v0.1 は本 ADR を北極星の解説として参照**し、五箇条 (immediate discipline) と4軸 (long-term mission) の二層構造を成立させる。
- **Phase 順序**: 1 → 2 → 3 → 4 を厳守。並行着手はしない (詳細: [[../culture/four-freedoms]])。
- **Charter v1.0 への昇格**は Phase 2 完了時または Phase 3 完了時を目処に再議論する。

## Alternatives Considered

1. **コミュニケーション専業に留まる**: 既存 Nostr クライアント群との差別化が「日本語デザイン」だけになり、長期競争で消耗する。
2. **4軸を同時着手**: polish (ぬるぬるの実質的な moat) が崩壊する確率が高い。スタートアップ的に死ぬ。
3. **4軸を機能タブとして並列追加**: LINE 模倣の悪い面 (タブ膨張) を再演する。第一条「日常を壊さない」と衝突。
4. **思想を前面に出した「Web3 アプリ」として打ち出す**: 日常体験を求める層を逃す。第三条「複雑さは裏側に隠す」と衝突。

## Why this fits NuruNuru

- **第一条「日常を壊さない」**: 思想を基盤に、所作を表層に置くことで日常体験を破壊しない。
- **第二条「日本語を第一級市民にする」**: 4軸の表層コピー (おひねり / お財布 / 道具) は日本語日常語で受け止める。
- **第三条「複雑さは裏側に隠す」**: Lightning / NIP-89 / 署名検証は基盤に隠す。
- **第四条「一貫性は新機能より重い」**: Phase 順序を守り、polish を犠牲にしない。
- **やらないこと「NIP が出たという理由だけで実装しない」**: 4軸は NIP 受動採用ではなく、能動的な10年計画として起票する。

## Consequences

### 良い影響

- 設計判断が「Nostr クライアントとして妥当か」から「主権的日常インターフェースとして妥当か」へと格上げされ、選択肢が広がる。
- 経済 / 配布の自由を求める日本のユーザー層 (表現者・同人・小規模事業者・個人開発者) に対する明確なポジションが取れる。
- 競合 (国内外の Nostr クライアント、Web2 メッセンジャー、Web3 ソーシャル) との差別化軸が明確になる。

### 悪い影響 / 技術的負債

- スコープ膨張のリスクが恒常化する。Crit と ADR と Phase ロードマップが防壁。
- ストア審査 (App Store / Play) との関係が将来的に緊張する可能性。命名・UI で共存設計を維持する。
- 「ぬるぬる = 政治的なアプリ」と誤読されるリスク。[[../culture/copy-style]] と [[../culture/not-doing]] で表層から思想語彙を排除する。
- バックエンドの複雑性が増す (Lightning ノード / NWC / mini-app sandbox 等の運用負荷)。

### 将来の見直し条件

- Phase 1 完了時に再評価。polish が落ちている場合は Phase 2 着手を遅らせる。
- Bitcoin / Lightning の規制環境が日本で大きく変化した場合 (例: 強い規制が入る、または逆に明確な合法フレームができる) に方針再議論。
- mini-app の標準化動向 (NIP-89 周辺) が大きく動いた場合に方針再議論。
- ストア審査ポリシーの変化により本体配布の継続が困難になった場合、配布戦略を再議論。
