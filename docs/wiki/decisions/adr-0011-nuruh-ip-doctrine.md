# ADR-0011: ぬるる IP 憲章 (四箇条) を起票する

## Status

Proposed (2026-05-28)。Design Crit 2回連続の合意で Accepted へ昇格。詳細運用は [[../strategy/nuruh-ip-2026-05-28]] に記す。

## Context

ぬるぬるの公式マスコット「ぬるる」(とろける生き物 / うさぎ風 / 約90cm / 星好き / 8表情パターン) を、IP として中長期的にどう扱うかについて方針が未策定だった。マーケティング上は早期にグッズ化・公式キャラ化する選択肢もあるが、以下の前提を踏まえると別の道を取る必要がある:

- ぬるぬるは [[../culture/principles|五箇条]] および [[../culture/four-freedoms|Four Freedoms]] に基づき「主権的日常インターフェース」を志向しており、IP 戦略も同思想に整合する必要がある。
- [[../culture/not-doing]] により、中毒設計・公式キャラ濫用・ポップアップ通知・既存採用コピーの改変は禁止されている。
- 短期 KPI (DAU/WAU/滞在時間) で文化判断を曲げないことが原則化されている。
- 既存の Nostr クライアント群との差別化軸として、ファンの自由 (二次創作・同人物販) を**制度的に保証する** IP モデルは前例が乏しく、長期 moat になりうる。
- ぬるるは Phase 0 時点で「キャラ画像が存在するだけ」の状態であり、専用 npub / 絵文字パック / ライセンス文書はいずれも未整備。**先に憲章を立ててから具体物を作る順序**が安全。

実装着手前に IP の哲学を ADR として固定し、後続のすべての判断 (グッズ化 / コラボ / 商標 / 二次創作対応) の基準にする必要がある。

## Decision

**ぬるる IP を「商品ではなく住人」として育てる**。これを以下4箇条として憲章化する。本 ADR の本文がぬるる IP 憲章 v0.1 の正本である。

**第一条 ぬるるはユーザーである。**
ぬるぬるの利用者の一人として振る舞う。投稿し、おひねりを受け取り、たまに休む。運営の宣伝役ではない。

**第二条 ぬるるは商品ではない。**
公式グッズを急がない。物販より先に二次創作が走る順番を守る。公式は二次創作より遅れて来る。

**第三条 ぬるるは溶ける。**
無理に登場させない。月間テーマや季節に合わせて、ゆっくり現れ、ゆっくり消える。24時間出ずっぱりにしない。

**第四条 ぬるるは誰のものでもない。**
描いていい、真似ていい、なりきっていい。商標で囲わず、ガイドラインで開く。取り締まり件数の目標は 0件 とする。

**変更プロセス**: 本ADRの四箇条の変更には Design Crit 2回連続の合意を要する。具体運用 (KPI 値・ライセンス階段・施策内訳) は [[../strategy/nuruh-ip-2026-05-28]] で更新可とし、別 ADR を要しない。

## Alternatives Considered

1. **公式マスコットとして早期に商品化 (典型ルート)** — 短期売上が立つが、第二条が許容できず、二次創作が萎縮する。第四条にも反する。長期 moat にならない。
2. **キャラを作らない (ミニマリズム)** — Charter 五箇条との整合性は最高だが、日本市場のキャラ文化を活用できず、差別化軸を1つ放棄することになる。
3. **完全パブリックドメイン宣言 (CC0 等)** — 第四条と整合性が高いが、悪意ある第三者の商標濫用に対する最低限の防御 (商標確保) が困難になる。本ADRでは「商標は最小限取るがファンの利用制約に使わない」とする折衷案を取る。
4. **キャラの世界観だけ固定し、ライセンスは未明文化** — 現状維持。グッズ化の問い合わせが来た際に毎回 ad-hoc 判断になり、運営側のコストが上がる。ADR-0011 + 戦略文書で先に決めておく方が安い。
5. **NFT / トークン的な所有モデル** — Charter v0.1 (Lightning / NIP-57 までしか言及せず) および [[../culture/not-doing]] (「Web3」「Bitcoin」を表層に出さない) と衝突する。採用しない。

## Why this fits NuruNuru

- **第一条「日常を壊さない」**: ぬるるをポップアップ通知や中毒設計に使わない (本ADR第三条「溶ける」が下支え)。
- **第二条「日本語を第一級市民にする」**: ぬるるのボイスガイドはやわらかい敬体。直訳キャラ口調を採用しない。[[../culture/copy-style]] に従う。
- **第三条「複雑さは裏側に隠す」**: ぬるる本体 npub の NIP-46 bunker 運用 (2-of-N 合議) はユーザー画面に出さない。
- **第四条「一貫性は新機能より重い」**: 公式物販は小ロット・不定期・再販なし。二次創作の優先順位を制度で守る。Phase 順序を厳守。
- **第五条「かわいさと、秘密鍵への厳格さを、同時に持つ」**: ぬるる本体鍵を 2-of-N で守ることで、「かわいいキャラの厳密な鍵管理」を体現する。
- **やらないこと「NIP が出たという理由だけで実装しない」**: 本 ADR も「キャラがあるから売る」ではなく、「四箇条に適合するから動く」順序を取る。
- **やらないこと「DAU/WAU で文化判断を曲げない」**: KPI 6軸とガードレール 7軸の二層構造で、文化指標が短期数値で曲がらない構造を作る (詳細は戦略文書)。

## Consequences

### 良い影響

- 二次創作・同人活動コミュニティへの明確なポジショニングが取れる (年商100万円までの届出不要は L2 階段で制度化)。
- ぬるる関連の判断 (グッズ化問い合わせ / コラボ / 商標) を四箇条で機械的にふるい分けられ、運営コストが下がる。
- 第四条「誰のものでもない」が機能すれば、ぬるるはぬるぬるアプリの境界を越えて自走する可能性がある (例: 他クライアントでも使われる絵文字パック、Nostr 全体への滲出)。
- 短期 KPI 圧力下でも、文化判断が ADR と戦略文書の二重防御で守られる。
- 海外 IP 直訳ではない、日本発のキャラ IP モデルとして文書化された前例ができる。

### 悪い影響 / 技術的負債

- 短期売上 (公式グッズ売上) を意図的に放棄する。BS/PL 上の貢献は Phase 2 以降まで遅延する。
- L2 年商閾値 100万円や「取り締まり件数 0」の運用が、悪意ある第三者ケース (商標濫用での消費者被害) に耐えるかは未検証。例外条項の要否を Phase 1 で再議論する。
- ぬるる本体 npub の 2-of-N 合議の技術構成 (FROST / Shamir / bunker 内部多重署名) が未確定。Phase 0 Week 1-2 で技術検証が必要。
- 「公式キャラと名乗らない」運用は、外部メディア取材・コラボ提案時に説明コストを生む (毎回「住人です」と説明する必要)。
- 二次創作の品質統制を意図的に放棄するため、ぬるる文脈で不適切な作品が流通するリスクがあるが、第四条はこれを許容する設計。

### 将来の見直し条件

- Phase 1 完了時 (3〜6ヶ月後) に KPI 6軸 + ガードレール 7軸の実績で再評価。ガードレールが1本でも崩れていれば四箇条の運用を見直す。
- L2 年商閾値 100万円が同人作家コミュニティ実態と乖離した場合、戦略文書側で閾値を更新 (ADR 改訂は不要)。
- 商標濫用での消費者被害が発生した場合、「取り締まり件数 0」原則に例外条項を追加する ADR を起票する。
- Phase 2 (6〜12ヶ月後) に「ぬるるの日」(8/8 提案) 第1回を実施し、その実績を基に戦略文書を v2.0 に更新する。
- Charter v1.0 昇格時 (Phase 4) に、本 ADR を「ぬるる IP 憲章 v1.0」へ昇格させるか、別文書へ分離するか再議論する。
