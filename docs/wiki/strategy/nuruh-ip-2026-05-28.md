# ぬるる IP マーケティング & 成長戦略 v1.0

> **ステータス**: Proposed (2026-05-28)。即決3事項 (§9) は Design Crit にかける前提。
> **対応 ADR**: [[../decisions/adr-0011-nuruh-ip-doctrine]] (IP 憲章4箇条)。

## Summary

ぬるぬるの公式マスコット「ぬるる」を、短期的なキャラクター商売ではなく **長期文化資産** として育てるための戦略 v1.0。「**商品ではなく、住人にする**」を中核ポジショニングとし、以下5層で組み立てる:

1. **ぬるるドクトリン4箇条** — IP 憲章 (ADR-0011 化)
2. **3層接点モデル** — 接触 / 関与 / 共生
3. **5つの成長ループ** — 日常 / 二次創作 / プロダクト内 / 物理 / コラボ
4. **ライセンス階段 L0〜L4** — 二次創作の自由を制度で保証
5. **KPI 6軸 + ガードレール7軸** — 文化指標を短期数値で曲げない

短期 KPI の追求でこの順序を曲げない。90日で骨格、12ヶ月で日常、24ヶ月で文化を組み上げる。Charter v0.1 五箇条および Four Freedoms ([[../decisions/adr-0008-four-freedoms-mission]]) と Phase 同期する。

## Current behavior

本ページ起票時点 (2026-05-28) ではぬるるは以下の状態:

- キャラクター画像 (とろける生き物 / うさぎ風 / 約90cm / 星好き / 8表情パターン) は存在。
- 8表情を活用した NIP-30 絵文字パックは未配布。
- 専用 npub / NIP-46 bunker は未発行。
- 「ぬるるの日」未制定。
- ライセンスガイドラインは明文化なし。
- 二次創作実数・言及密度は計測未開始。

本戦略はこれらを 90日で Phase 0 として揃え、その後 Phase 1〜4 へ進める。

## 1. ポジショニング

> **ぬるるは、ぬるぬるの公式マスコットではない。ぬるぬるの最初の住人である。**

「公式キャラ」と名乗らないことが最大の戦略。運営が所有していると宣言した瞬間に二次創作は萎縮しファンは消費者になる。ぬるるは**運営も一参加者として接する存在**として置く。

| 軸 | 一般的なキャラ IP | ぬるる |
|---|---|---|
| 所有 | 運営/ライセンサー | 誰のものでもない |
| 関係 | ファン↔キャラ | 隣人↔隣人 |
| 出現 | キャンペーン時 | 毎日のリズム |
| 物販 | 公式が一次販売 | 二次創作が一次、公式は遅れて来る |
| 成功指標 | 売上・知名度 | 言及密度・二次創作数・定着 |

## 2. ぬるるドクトリン四箇条 (IP 憲章)

**第一条 ぬるるはユーザーである。** ぬるぬるの利用者の一人として振る舞う。投稿し、おひねりを受け取り、たまに休む。運営の宣伝役ではない。

**第二条 ぬるるは商品ではない。** 公式グッズを急がない。物販より先に二次創作が走る順番を守る。公式は二次創作より遅れて来る。

**第三条 ぬるるは溶ける。** 無理に登場させない。月間テーマや季節に合わせて、ゆっくり現れ、ゆっくり消える。**24時間出ずっぱりにしない**。

**第四条 ぬるるは誰のものでもない。** 描いていい、真似ていい、なりきっていい。商標で囲わず、ガイドラインで開く。**取り締まり件数の目標は 0件**。

> この四箇条は [[../decisions/adr-0011-nuruh-ip-doctrine|ADR-0011]] として記録。変更には Design Crit 2回連続の合意を要する。

## 3. 3層接点モデル

| 層 | 名称 | 意味 | 具体例 |
|---|---|---|---|
| **層1** | 接触 (Surface) | 初対面の人が説明されずに「いる」と気づく | ローディング小演出、投稿欄プレースホルダー、NIP-30 絵文字パック、空状態イラスト |
| **層2** | 関与 (Engage) | 月に数回、距離が縮まる | おやつ15時 / おやすみ23時 / 月例とろけ便り / 週末ぬるる図鑑 |
| **層3** | 共生 (Symbiosis) | 自分の生活の一部になる | ぬるるアイコン使用、口調を真似た投稿、ステッカー貼付、ぬいぐるみ写真 |

**禁則** (第三条 + [[../culture/not-doing]] 準拠): ポップアップ通知でぬるるを出さない。中毒設計しない。層3に直接介入しない (層1〜2が機能していれば自然に育つ)。

## 4. 五つの成長ループ

| ループ | 仕組み | 仕掛け |
|---|---|---|
| ① **日常投稿** | おやつ15時 → ユーザー応答 → ぬるるが翌日いいね → 翌日もおやつ15時 | いいねは thumbs-up のみ。ぬるるからのいいねは1日上限で希少性確保 |
| ② **二次創作** | ファンアート → 週末ぬるる図鑑紹介 → 描き手増 → 図鑑が太る | 描き手表記必須。ぬるる本体アカウントから「ありがとう」一言 |
| ③ **プロダクト内** | 絵文字パック使用 → 反応文化 → 投稿増 → ぬるるが反応 | 8表情起点、季節ごと3〜5表情追加 (年間20表情上限) |
| ④ **物理** | ステッカー/ZINE/ぬいぐるみ → 写真投稿 → 欲しがる → 次の頒布 | 公式物販は**小ロット/不定期/再販なし**で二次創作物販を妨げない |
| ⑤ **コラボ** | 作家/地域/お店コラボ → 新しい人が来る | **年4本まで** (多すぎるとぬるるが薄まる) |

18. 絵本 / 短編アニメ (年1本、Phase 2以降)

## 6. ライセンス階段 L0〜L4

| L | 内容 | 必要なこと |
|---|---|---|
| **L0** 鑑賞 | 見る/読む/真似る/なりきる | 何もいらない |
| **L1** 二次創作 | イラスト/漫画/小説/動画/音楽 | 何もいらない (出典記載は任意) |
| **L2** 同人物販 | コミケ/通販/BOOTH 等 | **年商100万円までは届出不要**、超える場合のみ一報 |
| **L3** 商用利用 | 企業グッズ/広告/コラボ商品 | 事前相談 (Design Crit にかける) |
| **L4** 公式コラボ | ぬるぬる運営との共同企画 | 招待制 |

**運用原則:**
- L0〜L2 はガイドラインのみで運用し書類を求めない。
- L2 届出は**年1回まとめてOK**、罰則なし、忘れても咎めない。
- L3 判断基準は「四箇条に反していないか」のみ。売上規模で差別しない。
- 商標は「ぬるる」「nuruh」を最小限取り、**ファンの利用を制約する目的では使わない**。

| 儀式運用 | 1 (兼任可) | おやつ15時 / おやすみ23時の運用、欠勤時の代替 |

## 9. 即決 3 事項 (Design Crit にかける提案)

### 決定1: L2 同人物販の閾値
**提案: 1作家あたり年商 100万円までは届出不要。** コミケ的自由を明文化しないと心理的負担が残る。100万円は同人活動の実態に即した上限。超えた場合も罰則なく翌年から一報。

### 決定2: ぬるる本体 npub の鍵管理
**提案: NIP-46 (Nostr Connect) による bunker 構成。署名権限は Design Crit 参加者 2名以上の合議 (2-of-N)。** 鍵本体は HSM またはハードウェアウォレットに格納し、平文では一切持たない。一人で持つと事故時に復旧不能、誰でも触れると四箇条が崩れる。詳細は [[../decisions/adr-0003-ios-external-signing-uses-nip46|ADR-0003]] 参照。

### 決定3: 「ぬるるの日」の制定
**提案: 8月8日「ぬるぬる」の日。** 語呂・覚えやすさ・夏で動きやすさで他候補 (キャラ確定日 / リリース日) より優位。毎年 8/8 はおひねり還元・限定壁紙・図鑑特別号・ぬいぐるみ世界旅当選発表を行う。**売る日ではなく祝う日**にする。

## 13. 失敗モードと防御

| 失敗モード | 兆候 | 防御 |
|---|---|---|
| 過剰商品化 | 公式グッズが月次連発される | 第二条 ADR / 物販は年計画固定 |
| 同時着手で polish 崩壊 | 月内施策が5本超 | Phase ロードマップ厳守 |
| 「公式キャラ」化で二次創作萎縮 | 二次創作数が3ヶ月連続減 | 運営も一参加者宣言を毎月強化 / 図鑑で頻度上げる |
| 海外 IP 直訳化 | コピー音読適合率低下 | [[../culture/copy-style]] 月次レビュー |
| ぬるる過剰露出疲れ | 言及/日が高止まり後に急減 | 第三条「溶ける」発動。月間テーマを「お休みのぬるる」に |
| 鍵事故 | bunker 警告 | 四半期監査 / 即時 npub ローテーション手順を Phase 0 で確立 |
| 取り締まり要請 | 商標侵害の通報 | **取り締まらない**を原則とし、ガイドライン側を更新して対処 |

## 14. 危機対応プロトコル

| 事象 | 初動 | 公式声明 |
|---|---|---|
| ぬるる npub 漏洩 | bunker 停止 → 鍵ローテ → 新 npub 周知 | やわらかい敬体で事実のみ。煽らない |
| 二次創作炎上 (作家側の問題) | ぬるる本体は沈黙。図鑑から該当作品を**目立たぬよう**ローテで外す | 出さない |
| 商標トラブル要請 | 取り締まらない原則。ガイドライン明文化で対応 | ガイドライン更新の告知のみ |
| なりすまし | NIP-05 認証 + 既知 npub 周知を継続。法的措置はとらない | 周知のみ |
| 運営内部の四箇条違反 | Design Crit 緊急回。ADR で撤回明文化 | やわらかい謝罪、再発防止策を明示 |

**共通原則**: 危機時こそコピーの**音読適合率**を落とさない。早く出すより**ぬるるらしく**出す。

## Platform notes

- **絵文字パック (NIP-30)**: Web / Android / iOS の3層で同一セット同時提供。([[../nips/nip-30]], [[../ui/android-ios-sync]])
- **ぬるる npub の NIP-46 署名**: iOS は ADR-0003 準拠で NIP-46 経由。Android は NIP-55 (Amber) 既存導線も併用可だが、ぬるる本体鍵は NIP-46 bunker に集約する。
- **コピー (やわらかい敬体)**: 既存採用コピー (「もっと見る」「閉じる」「ホーム/トーク/ろくなな/タイムライン/ミニアプリ」) は不変。ぬるる本体投稿も既存コピー文化と矛盾しない口調で。

## Doctrine alignment

| 第条 | 適合理由 |
|---|---|
| 第一条 日常を壊さない | ポップアップ通知でぬるるを出さない。中毒設計しない。第三条「溶ける」と二重で防御。 |
| 第二条 日本語を第一級市民に | ボイスガイドはやわらかい敬体。直訳キャラ口調を採用しない。 |
| 第三条 複雑さは裏側に隠す | NIP-46 bunker / NIP-30 絵文字 / NIP-65 リレーをユーザー画面に出さない。 |
| 第四条 一貫性は新機能より重い | 公式物販は小ロット不定期、二次創作の優先順位を制度で守る。Phase 順序厳守。 |
| 第五条 かわいさと厳格さを同時に | ぬるる本体鍵を 2-of-N で守ることで「かわいいキャラの厳密な鍵管理」を体現。 |

## Open Questions

- 90日 KPI ベースライン (ぬるる言及 / 日 = 15 等) は仮置き。Phase 0 着手時に実測ベースで再設定する必要がある。
- L2 年商閾値 100万円は実態調査未実施の提案値。同人作家コミュニティへのヒアリングで微調整余地あり。
- ぬるる本体 npub の 2-of-N 合議の技術構成 (FROST? Shamir? bunker 内部多重署名?) は未確定。Phase 0 Week 1-2 で技術検証必要。
- 「ぬるるの日」を 8/8 にした場合のコミケ夏との衝突調整 (作家側スケジュール) は未確認。
- 海外コミュニティ (英語圏 Nostr) への自然展開 Phase 3 のトリガー条件未定義。
- L3 商用利用の Design Crit 判定で「四箇条適合」を機械的に判定する基準は未策定。事例 3〜5件を Phase 1 で蓄積してから明文化する。
- 取り締まり件数 = 0 の方針が、悪意ある第三者の商標濫用 (例: ぬるる類似商品で消費者被害) ケースに耐えうるか。例外条項の要否を Phase 1 で議論。
